# 3. ការកោងចំហៀងរបស់សសរ

## គោលគំនិត

សសរដែលទទួលសម្ពាធ និងមានភាពស្ដើងអាចបត់ទៅចំហៀង ហើយបរាជ័យនៅកម្លាំង **ទាបជាង** កម្លាំងហូរពេញផ្នែក $N_{pl}$។ សមាមាត្ររវាងភាពធន់កោង និងកម្លាំងហូរពេញគឺ **កត្តាបន្ថយ** $\chi$។ វាអាស្រ័យលើភាពស្ដើងប្រៀបធៀប $\bar{\lambda}$ និងភាពមិនល្អឥតខ្ចោះរបស់ធាតុ។

## សមីការ

កម្លាំងហូរពេញ និងភាពស្ដើងប្រៀបធៀប៖

$$
N_{pl} = A\,f_y
\qquad
\bar{\lambda} = \frac{L_{cr}/i}{\lambda_1}
\qquad
\lambda_1 = \pi\sqrt{\frac{E}{f_y}}
$$

កត្តាបន្ថយ៖

$$
\Phi = 0.5\left[1 + \alpha\,(\bar{\lambda} - 0.2) + \bar{\lambda}^{2}\right]
\qquad
\chi = \frac{1}{\Phi + \sqrt{\Phi^{2} - \bar{\lambda}^{2}}} \le 1.0
$$

ភាពធន់កោងរចនា៖

$$
N_{b,Rd} = \frac{\chi\,A\,f_y}{\gamma_{M1}}
$$

កត្តាមិនល្អឥតខ្ចោះ $\alpha$ អាស្រ័យលើ **ខ្សែកោងកោង**៖

| ខ្សែកោង | a0 | a | b | c | d |
|---|---|---|---|---|---|
| $\alpha$ | 0.13 | 0.21 | 0.34 | 0.49 | 0.76 |

ខ្សែកោងដែលត្រូវប្រើសម្រាប់ផ្នែក I រមូរ អាស្រ័យលើសមាមាត្រ $h/b$ កម្រាស់ស្លាប និងអ័ក្សដែលត្រូវពិនិត្យ។ សូមមើលតារាងជ្រើសរើសក្នុងស្តង់ដាររចនា។

## ឧទាហរណ៍គណនា៖ IPE 330, S235

ទិន្នន័យ៖ $A = 62.6$ cm², $i_y = 137$ mm, $i_z = 35.5$ mm, $f_y = 235$ N/mm² និង $\gamma_{M1} = 1.0$។ ប្រវែងកោងគឺ 6 m ជុំវិញអ័ក្ស y និង 3 m ជុំវិញអ័ក្ស z (មានទ្រនាប់កណ្ដាលជុំវិញអ័ក្សខ្សោយ)។ នៅទីនេះ $h/b = 2.06$ និង $t_f = 11.5$ mm ដូច្នេះប្រើខ្សែកោង **a** សម្រាប់អ័ក្ស y និងខ្សែកោង **b** សម្រាប់អ័ក្ស z។

ដំបូង គណនាតម្លៃដែលមិនអាស្រ័យលើអ័ក្ស៖

$$
N_{pl} = 6260 \times 235 / 1000 = 1471.1\ \text{kN}
\qquad
\lambda_1 = \pi\sqrt{\frac{210\,000}{235}} = 93.91
$$

| បរិមាណ | អ័ក្ស y | អ័ក្ស z |
|---|---:|---:|
| $L_{cr}$ [mm] | 6000 | 3000 |
| $L_{cr}/i$ | 43.80 | 84.51 |
| $\bar{\lambda}$ | 0.466 | 0.900 |
| ខ្សែកោង, $\alpha$ | a, 0.21 | b, 0.34 |
| $\Phi$ | 0.637 | 1.024 |
| $\chi$ | 0.934 | 0.661 |
| $N_{b,Rd}$ [kN] | 1374.6 | 972.8 |

**អ័ក្សខ្សោយជាករណីគ្រប់គ្រង**៖ $N_{b,Rd} = 972.8$ kN។ បើកម្លាំងរចនា $N_{Ed} = 500$ kN នោះកម្រិតប្រើប្រាស់គឺ $500 / 972.8 = 0.51$។

=== "Python"

    ```python
    import numpy as np

    def flexural_buckling(A_cm2, i_mm, Lcr_mm, alpha, fy=235.0, E=210000.0, gamma_M1=1.0):
        lam1 = np.pi * np.sqrt(E / fy)
        lam = (Lcr_mm / i_mm) / lam1                      # relative slenderness
        phi = 0.5 * (1 + alpha * (lam - 0.2) + lam**2)
        chi = min(1.0, 1.0 / (phi + np.sqrt(phi**2 - lam**2)))
        Nb_Rd = chi * A_cm2 * 100 * fy / gamma_M1 / 1000   # kN
        return lam, chi, Nb_Rd

    print(flexural_buckling(62.6, 137.0, 6000, alpha=0.21))   # y-axis
    print(flexural_buckling(62.6, 35.5, 3000, alpha=0.34))    # z-axis
    ```
