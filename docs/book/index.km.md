# មូលដ្ឋានរចនាធាតុដែកសំណង់

មគ្គុទ្ទេសក៍អនុវត្តអំពីការរចនាធាតុដែកសំណង់ ដែលមានជំពូកស្តីពីការចាត់ថ្នាក់ផ្នែកកាត់ និងភាពធន់នឹងការកោង។ មូលដ្ឋានរចនាគឺ Eurocode 3 (EN 1993-1-1:2022)។

## មាតិកា

1. [សេចក្តីផ្តើម](01-introduction.md)៖ វិសាលភាព សញ្ញាសម្គាល់ និងឯកតា។
2. [ការចាត់ថ្នាក់ផ្នែកកាត់](02-classification.md)៖ ការកោងក្នុងផ្នែក និងថ្នាក់ទាំងបួន។
3. [ការកោងចំហៀងរបស់សសរ](03-buckling.md)៖ ខ្សែកោងកោង និងឧទាហរណ៍គណនា។

## របៀបអានសៀវភៅនេះ

- ជំពូកនីមួយៗចាប់ផ្តើមពីគោលគំនិត បន្ទាប់មកសមីការ និងឧទាហរណ៍គណនា។
- ឧទាហរណ៍ប្រើផ្នែកដែករមូរ IPE 330 និងដែកថ្នាក់ S235។ វិមាត្រយោងតាមតារាងរបស់ក្រុមហ៊ុនផលិត។
- មានបង្ហាញកូដ Python ដើម្បីឱ្យអ្នកអាចធ្វើការគណនាឡើងវិញ។

!!! warning "ការបដិសេធការទទួលខុសត្រូវ"
    សៀវភៅនេះសម្រាប់ការសិក្សា។ សូមផ្ទៀងផ្ទាត់ការគណនាដោយឯករាជ្យ និងប្រើកំណែបច្ចុប្បន្ននៃស្តង់ដាររចនាដែលអនុវត្តចំពោះគម្រោងរបស់អ្នក។
