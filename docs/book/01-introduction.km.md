# 1. សេចក្តីផ្តើម

## វិសាលភាព

សៀវភៅនេះពន្យល់ពីការត្រួតពិនិត្យ **ធាតុសំណង់** ដូចជាធ្នឹម ឬសសរ ចំពោះរបៀបបរាជ័យទូទៅ៖

- ភាពធន់របស់ផ្នែកកាត់,
- ការកោងរបស់ធាតុដែលទទួលសម្ពាធ,
- ការកោងរមួលចំហៀងរបស់ធ្នឹម,
- ឥទ្ធិពលរួមរវាងការបត់ និងសម្ពាធអ័ក្ស។

## សញ្ញាសម្គាល់

| សញ្ញា | អត្ថន័យ | ឯកតា |
|---|---|---|
| $A$ | ផ្ទៃក្រឡាផ្នែកកាត់ | cm² |
| $f_y$ | កម្លាំងចាប់ផ្តើមហូររបស់ដែក | N/mm² |
| $E$ | ម៉ូឌុលយឺតភាព (210 000) | N/mm² |
| $i$ | កាំនិចលភាព | mm |
| $L_{cr}$ | ប្រវែងកោង | m |
| $N_{Ed}$ | កម្លាំងអ័ក្សរចនា (យកសម្ពាធជាវិជ្ជមាន) | kN |
| $N_{b,Rd}$ | ភាពធន់កោងរចនា | kN |
| $\gamma_{M1}$ | មេគុណផ្នែកសម្រាប់ស្ថិរភាព | - |

## ឯកតា

កម្លាំងប្រើ kN ម៉ូម៉ង់ប្រើ kNm ប្រវែងប្រើ mm ឬ m (បញ្ជាក់ក្នុងសមីការនីមួយៗ) និងសម្ពាធប្រើ N/mm²។ ឯកតានៃលទ្ធផលនីមួយៗត្រូវបានបង្ហាញ។

!!! note "អនុសញ្ញាសញ្ញា"
    យកកម្លាំងសម្ពាធជាវិជ្ជមាន។ កម្លាំងអ័ក្សអវិជ្ជមានមានន័យថាកម្លាំងទាញ។

## របៀបគណនាឧទាហរណ៍

តម្លៃទាំងអស់ក្នុងឧទាហរណ៍ត្រូវបានគណនាដោយកម្មវិធី Python ខ្លីមួយ ដែលបង្ហាញនៅចុងជំពូកនីមួយៗ។ អ្នកអាចចម្លងកូដ ហើយប្តូរទិន្នន័យបញ្ចូលបាន។
