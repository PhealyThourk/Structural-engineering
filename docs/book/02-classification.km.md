# 2. ការចាត់ថ្នាក់ផ្នែកកាត់

## គោលគំនិត

បន្ទះដែកស្តើងដែលទទួលសម្ពាធអាចកោងក្នុងផ្នែក **មុន** ពេលដែកឈានដល់ការហូរ។ បន្ទះដែលស្តើងជាងមានទំនោរកោងមុន។ ដូច្នេះស្តង់ដាររចនាបែងចែកផ្នែកកាត់ជា **ថ្នាក់** បួន តាមឥរិយាបថពេលទទួលការបត់ និងសម្ពាធ។

| ថ្នាក់ | ឥរិយាបថ | ផលចំពោះការរចនា |
|---|---|---|
| 1 | ឈានដល់ម៉ូម៉ង់ប្លាស្ទិក និងអាចបង្វិលបានច្រើន | អាចប្រើការវិភាគសកលប្លាស្ទិក |
| 2 | ឈានដល់ម៉ូម៉ង់ប្លាស្ទិក ប៉ុន្តែការបង្វិលមានកម្រិត | អាចប្រើភាពធន់ម៉ូម៉ង់ប្លាស្ទិក |
| 3 | ហូរនៅសរសៃខាងក្រៅ ហើយការកោងក្នុងផ្នែកកំណត់សមត្ថភាពនៅចំណុចនោះ | ប្រើភាពធន់យឺត ឬវិធីអេល៉ាស្តូ-ប្លាស្ទិក |
| 4 | កោងក្នុងផ្នែកមុនពេលហូរ | ត្រូវប្រើផ្នែកកាត់មានប្រសិទ្ធភាព |

## ភាពស្ដើងរបស់បន្ទះ

ភាពស្ដើងរបស់ផ្នែកបន្ទះគឺសមាមាត្ររវាងទទឹង $c$ និងកម្រាស់ $t$។ គេប្រៀបធៀបវានឹងកម្រិតដែលអាស្រ័យលើកម្លាំងចាប់ផ្តើមហូរ តាមកត្តា

$$
\varepsilon = \sqrt{\frac{235}{f_y}}
$$

ដោយ $f_y$ មានឯកតា N/mm²។ ដែកថ្នាក់ខ្ពស់មាន $\varepsilon$ តូច ដូច្នេះកម្រិតអនុញ្ញាតកាន់តែតឹងរ៉ឹង។

| ថ្នាក់ដែក | $f_y$ [N/mm²] | $\varepsilon$ |
|---|---:|---:|
| S235 | 235 | 1.000 |
| S275 | 275 | 0.924 |
| S355 | 355 | 0.814 |
| S420 | 420 | 0.748 |
| S460 | 460 | 0.715 |

!!! tip "តើកម្រិតនៅឯណា?"
    កម្រិត $c/t$ សម្រាប់ថ្នាក់នីមួយៗមាននៅក្នុងតារាងស្តង់ដាររចនា។ កម្រិតនោះអាស្រ័យលើបន្ទុក (បត់ សម្ពាធ ឬទាំងពីរ) ហើយមិនបានចម្លងមកទីនេះទេ។ សូមយោងតាមកំណែស្តង់ដារដែលអ្នកប្រើ។

## ឧទាហរណ៍គណនា៖ IPE 330

វិមាត្រ IPE 330 គឺ $h = 330$ mm, $b = 160$ mm, $t_w = 7.5$ mm, $t_f = 11.5$ mm និង $r = 18$ mm។

**ជញ្ជាំងកណ្ដាល** (ផ្នែកខាងក្នុង រវាងកាំកោង):

$$
c_w = h - 2t_f - 2r = 330 - 2(11.5) - 2(18) = 271\ \text{mm}
\qquad
\frac{c_w}{t_w} = \frac{271}{7.5} = 36.1
$$

**ស្លាប** (ផ្នែកលយចេញ):

$$
c_f = \frac{b - t_w - 2r}{2} = \frac{160 - 7.5 - 2(18)}{2} = 58.25\ \text{mm}
\qquad
\frac{c_f}{t_f} = \frac{58.25}{11.5} = 5.07
$$

ជញ្ជាំងកណ្ដាលជាផ្នែកស្ដើងជាងគេរបស់ផ្នែកកាត់នេះ៖ តម្លៃ $c/t$ របស់វាធំជាងស្លាបច្រើន ដូច្នេះជញ្ជាំងកណ្ដាលជាអ្នកកំណត់ថ្នាក់ក្រោមសម្ពាធ។

!!! note "ជំហានបន្ទាប់"
    ប្រៀបធៀប $c_w/t_w$ និង $c_f/t_f$ ជាមួយកម្រិតក្នុងស្តង់ដារសម្រាប់ករណីបន្ទុករបស់អ្នក។ ជំពូក [ការកោងចំហៀង](03-buckling.md) បន្តដោយពិនិត្យផ្នែកដែលមិនត្រូវបានកំណត់ដោយការកោងក្នុងផ្នែក។
