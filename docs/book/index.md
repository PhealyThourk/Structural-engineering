# Steel Member Design Basics

A short, practical introduction to the design of steel members. The book is a **sample**: it shows
how a book is organised on this site. Replace the chapters with your own text.

## Contents

1. [Introduction](01-introduction.md): scope, notation and units.
2. [Cross-section classification](02-classification.md): local buckling and the four classes.
3. [Flexural buckling](03-buckling.md): the buckling curves and a worked example.

## How to read this book

- Every chapter starts with the **idea**, then the **equations**, then a **worked example**.
- The examples use the rolled section **IPE 330** in steel **S235**. The dimensions come from the
  manufacturer's section table.
- Python code is shown so that you can repeat every calculation.

!!! warning "Disclaimer"
    The book is for learning. Always check calculations independently and use the current
    edition of the design standard that applies to your project.
