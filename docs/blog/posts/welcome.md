# Welcome to Engineering Notes

This site contains a free book and short articles on structural steel design.

<!-- more -->

## What you will find here

- **The book**: a step-by-step introduction, one chapter per topic.
- **Articles**: one idea per article, with the numbers shown.
- **A web tool** that checks I- and H-sections and writes a PDF report.

## How an article is written

Each article is a single Markdown file in the folder `docs/blog/posts/`. The first lines (between
the two `---` lines) hold the date and the categories. Equations are written between dollar signs,
for example $\chi = 1/(\Phi + \sqrt{\Phi^2 - \bar{\lambda}^2})$.
